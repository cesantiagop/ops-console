# ADR 0001: Record design decisions as ADRs

**Status:** accepted · 2026-11-11

## Context
This project exists to show *how* I make engineering decisions, not only the code that results.

## Decision
Every significant choice (data conventions, pagination strategy, write safety, secrets, tooling) gets a short
Architecture Decision Record here: context, decision, consequences. Numbered, never deleted; a changed mind is a
new ADR that supersedes the old one.

## Consequences
Reviewers can follow the reasoning without reading all the code. Writing the ADR first also forces the trade-off
to be stated before building.
